# NAGPUR-R2

**Risk-to-Response Traffic Intelligence**

AI-Based Traffic Risk Heatmap and Police Deployment Decision Support for Nagpur City.

## Core pipeline

```text
Data
 ↓
M1 Risk Prediction
 ↓
M2 Risk Propagation
 ↓
Risk Shadow
 ↓
M3 Police Optimization
 ↓
XAI
 ↓
What-if Simulation
 ↓
Command Center
```

## MVP
- 6–8 simulated Nagpur pilot locations
- 15-minute prediction horizon
- synthetic/open data
- NetworkX graph
- risk propagation
- Risk Shadow
- OR-Tools deployment
- React + Leaflet dashboard

## Success criteria
The demo must show:
1. current risk
2. future risk
3. heatmap
4. propagation path
5. Risk Shadow
6. police allocation
7. incident simulation
8. dynamic redeployment
9. explanation
10. human override
11. baseline comparison

Synthetic values must be clearly labeled. The prototype does not claim access to live Nagpur Police systems.
